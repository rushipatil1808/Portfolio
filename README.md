# Rushikesh Patil - Portfolio

**Live Demo:**[ [https://portfolio-chi-sepia-97.vercel.app](https://portfolio-chi-sepia-97.vercel.app)](https://portfolio-rushipatil1808-8560-rushipatil1808.vercel.app/)

A clean, modern, and minimal personal portfolio built with React, Vite, and Tailwind CSS. Designed to showcase projects, skills, and certifications for an AI/ML Engineer role.

## 🚀 Features
- **Modern UI:** Clean off-white and coral/teal color palette.
- **Fully Responsive:** Optimized for Mobile, Tablet, and Desktop displays.
- **Scroll Animations:** Smooth fade-in animations on scroll.
- **Performance Optimized:** Fast load times with Vite bundling.
- **Production Ready:** Pre-configured for easy deployment to Vercel or GitHub Pages.

## 💻 Tech Stack
- React 18
- Vite
- Tailwind CSS
- PostCSS
- DevIcons & FontAwesome

## 🛠️ Local Development Setup

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Start Development Server:**
   ```bash
   npm run dev
   ```

3. **Build for Production:**
   ```bash
   npm run build
   ```

## 🌍 Deployment to Vercel
1. Push your repository to GitHub.
2. Log into [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import your GitHub repository.
4. Vercel will automatically detect the **Vite** framework.
5. Click **Deploy**. Your site will be live in seconds!
